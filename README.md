> **"Turning Data into Insights and Insights into Decisions."**

Welcome to my personal portfolio repository! This is a modern, minimalist, high-tech portfolio website built to showcase my data analytics projects, interactive dashboards, SQL transformations, and business intelligence solutions.

🌐 **Live Website:** [https://data-analyst-portfolio-umber.vercel.app](https://data-analyst-portfolio-umber.vercel.app)

---

## 📊 Core Portfolio Features

- **Executive BI Playground:** Embedded interactive analytics dashboard simulating real-world metrics (Revenue Trends, Claims Volumes, Conversion Rates) with dynamic demographic filtering and Recharts telemetry.
- **Dynamic GitHub Sync:** Directly integrates with GitHub REST API to showcase live repositories, languages, and stars from [`@rakhisahu2608-spec`](https://github.com/rakhisahu2608-spec).
- **Featured Case Studies:**
  - **Insurance Claims Analysis Dashboard** (Power BI, DAX, Power Query)
  - **E-Commerce Sales & Customer Intelligence** (Python, SQL, Pandas, Power BI)
  - **Healthcare Patient Flow & Resource Optimization** (SQL, Python, Plotly)
  - **Financial Portfolio Risk Volatility Engine** (Python, NumPy, Statistics)
- **Technical Skills Matrix:** Interactive capability tabs with level indicators for Python, SQL, Power BI, Advanced Excel, Statistics, and Data Wrangling.
- **Modern High-Tech Aesthetic:** Dark mode primary theme, glassmorphic cards, telemetry micro-interactions, responsive across all screen sizes.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS
- **Visualization:** Recharts, Lucide Icons
- **Deployment:** Vercel Global Edge Network
- **Version Control:** Git, GitHub CLI (`gh`)

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/rakhisahu2608-spec/data-analyst-portfolio.git

# Navigate into project directory
cd data-analyst-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
